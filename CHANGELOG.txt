CHANGELOG
=========

Version: 2026-06-02
Summary: Implemented dataset ingestion, a scanning agent, training CLI options, dataset folder support, and team workflow guidance.

What was added
- `agent.py` — Phishing scanning agent: loads the trained model, flags signature patterns, prints prediction + confidence, and provides short assumptions for analysts.
- Dataset ingestion support in `generate_data.py` — loads CSV/TSV/JSON files, detects common text/label schemas (including `Email Text` / `Email Type`), and can recursively load `Datasets/`.
- `train.py` CLI options — `--dataset-paths`, `--model-path`, `--test-size` (falls back to synthetic generator when no paths are given).
- `sample_email.txt` — example email for quick `agent.py` testing.
- `CHANGELOG.txt` (this file) — now includes per-role next steps for team coordination.

What was changed
- `generate_data.py`: added robust parsing, label normalization, and graceful skipping of unsupported files when scanning directories.
- `train.py`: now accepts dataset paths and saves models to a configurable path.
- `README.md`: instructions for training with `Datasets/` and using `agent.py` were added.
