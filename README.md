# Lillteamet-Phishing-klassificerare
Utveckla en NLP-baserad klassificerare som identifierar phishing-mejl och skadliga URL:er. Extrahera features från e-posthuvuden, brödtext, URL-mönster och avsändarinformation för att bygga en robust detektionsmodell.

Dataset: Publika phishing-dataset (t.ex. Nazario phishing corpus, PhishTank)

Verktyg: scikit-learn, nltk eller spaCy, transformers (valfritt)
